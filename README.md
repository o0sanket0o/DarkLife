# Food Plaza digital menu

React + Vite. Edit prices in `src/menu.js`.

    npm install
    npm run dev        # local preview
    npm run build      # production build in dist/
    npm run qr -- https://your-menu-url.com   # makes menu-qr.png for printing

Deploy: Cloudflare Pages (build `npm run build`, output `dist`).
